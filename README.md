### 1. Sudoku Solver & Generator (`sudoku_final.pl`)
* **Domain:** Constraint Satisfaction / Puzzles / Mathematical Proofs
* **Description:** A 4x4 Sudoku solver and puzzle generator. It demonstrates how to enforce row, column, and block constraints dynamically.
* **Highlight:** The generator predicate can be used in a brute-force approach to mathematically prove the minimum number of given elements (clues) required to guarantee a unique solution in a 4x4 grid.
